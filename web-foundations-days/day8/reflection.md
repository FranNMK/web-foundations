# Course Reflection: Web Foundations

During the Web Foundations course, the most challenging concept was understanding distributed concurrency and race conditions—specifically how to prevent state corruption when multiple asynchronous requests target identical database records simultaneously. Initially, reasoning about database transactions, ACID isolation levels, and non-blocking I/O felt abstract. I overcame this challenge through hands-on experimentation: reproducing race conditions in relational databases, comparing optimistic concurrency versioning against pessimistic row-level locking (`SELECT ... FOR UPDATE`), and analyzing how atomic conditional updates guarantee invariant correctness. Tracing request lifetimes from edge proxies down to database engine row locks demystified distributed systems.

Reflecting on my QuickNotes capstone project, the primary area I would improve based on feedback is client-side offline synchronization and graceful degradation during network partitions. While the current implementation handles core CRUD operations and input validation reliably, it relies on synchronous network availability. If a user loses connectivity while drafting or tagging notes, unsaved state can be lost. To elevate the application to production grade, I would integrate IndexedDB with Service Workers to support local offline caching, along with an optimistic UI reconciliation strategy that queues pending mutations and resolves synchronization conflicts upon reconnection.

Looking ahead, I plan to deepen my expertise in distributed architectures, cloud-native backend systems, and high-throughput messaging patterns. Specifically, I want to master event-driven microservices using Apache Kafka and RabbitMQ, explore advanced database indexing and query plan optimization in PostgreSQL, and gain practical experience with container orchestration using Docker and Kubernetes. Building scalable, fault-tolerant infrastructure capable of handling millions of real-time events is the engineering frontier I am excited to pursue next.
